# 验收清单

## 已交付

- 本地 MQTT 配置流程与 HA 集成。
- 开关、1–32 档调速、水平 30°/60°/90° 与关闭、垂直摇头。
- 六个状态传感器、增量状态合并、断线和消息过期处理。
- 自动化测试与 Home Assistant 2026.10.2 运行时验证。

## 用户验收

1. 按 README 和部署指南配置 broker、DNS、HA MQTT 和 AirMate CN。
2. 确认出现风扇、水平角度选择器、垂直摇头开关及状态传感器。
3. 实测开关、约 31%/34%/37% 调速、水平角度、垂直摇头，并检查新上报是否回填。
4. 将速度设为 0% 后重新开机，确认设备行为与 HA 状态一致。
5. 用面板或遥控器改变设置，确认设备上报能同步；没有上报的字段保持 unknown。
6. 重载集成或重启 broker 后确认不会重放 retained 控制消息，收到新上报后状态恢复。
7. 检查诊断和日志不包含密码、完整报文或其他敏感身份信息。

## 已知边界

主动全量查询、模式/灯光/静音写入以及其他型号兼容性尚未确认。软件测试通过不等于机械动作已目视确认；最终动作由使用者现场检查。
